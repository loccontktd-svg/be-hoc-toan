# Bé Học Toán

Web app học toán cho bé mầm non (4–6 tuổi), chơi trên điện thoại và iPad.

**Chơi ngay:** mở trang GitHub Pages của repo này bằng Safari/Chrome → Chia sẻ → *Thêm vào MH chính*.

- 10 trò: Đếm số, Tìm số, Nhiều hay ít, Phép cộng, Phép trừ, Tập tô số, Hình học, Quy luật, Xem đồng hồ, Đếm tiền
- Giọng đọc tiếng Việt, độ khó tự điều chỉnh, ôn lại câu sai
- Sao đổi sticker, hành trình mở bạn đồng hành mới
- Chạy offline sau lần mở đầu tiên

Thêm/sửa câu đọc: sửa `phrases.js` rồi chạy `tools\tao_giong.bat` (cần Node + Python `edge-tts`).
